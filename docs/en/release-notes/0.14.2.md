# Nodvard Deck 0.14.2: security and fixes

## English

The web interface is in German only for now. Names of buttons, tabs, pages, and settings are given in German as they appear, with an English translation in parentheses.

### The essentials

A bugfix release focused on security. New features come with the next version.

- **Two-factor login:** Turning it on signs out all other devices.
- **Credentials:** Pi-hole and Nginx Proxy Manager addresses no longer show passwords, and Deck no longer triggers a Nextcloud account lockout through repeated requests.
- **First setup better protected:** The setup code is harder to guess.
- **Shield:** A deleted server now disappears from Shield and no longer counts in the score.
- **Backups:** An error in a Proxmox group backup only counts for the guests where it actually happened.

### What you need to do

Nothing special. With the update helper, update as usual via "Jetzt aktualisieren" (update now).

Only if your installation is **not set up yet** and you set the setup code yourself via an environment variable: it now needs at least 12 letters or digits. Otherwise Deck generates a random code that is shown in the container log.

### Security

- Turning on two-factor login signs out all other devices, just like changing the password. The device you turn it on from stays signed in.
- Before first setup, Deck now limits wrong setup codes regardless of the IP address.
- A setup code set via an environment variable needs at least 12 letters or digits and must not be a placeholder from the guide. Otherwise Deck generates a random code in the container log.
- First setup can only ever create one owner account.
- Compose files that are too large or too deeply nested are rejected with a hint.
- Pi-hole and Nginx Proxy Manager no longer accept an address that contains a username or password. Addresses already saved this way keep working. The overview, tile, app suggestion, and error messages hide the credentials in them or do not show the address at all.
- If Nextcloud rejects the saved credentials, Deck does not ask again for up to 30 minutes, not even via "Aktualisieren" (refresh). New credentials, changed settings, or "Verbindung testen" (test connection) end the pause right away.

### Fixed

- **Shield:** Deleted servers no longer appear in the overview, scans, and weekly report and no longer count in the score. Servers that are later merged with another entry stay in the report with all findings and are not counted twice.
- **Backups:** Errors of a Proxmox group backup are matched, based on the task log, only to the guests (VMs and containers) where they actually happened. Without a clear result, the run shows as "Job mit Fehlern, Gast unklar" (job with errors, guest unclear).
- **Backups:** The backup center no longer requests an unreadable task log again on every refresh.
- **Startseite (start page):** Containers with a failed health check no longer count as a running service and show as a warning.
- **ntfy:** The connection test checks the server's response and write access to the topic. Foreign web servers, denied access without a token, and tokens without write access are reported as errors.
- **Modules:** If the same module is turned on twice at the same time, Deck loads it only once and turns it off cleanly later.
- **Live messages:** A browser tab that no longer accepts live messages no longer holds up messages to other tabs.

### Good to know

- **Full list:** All changes are in Nodvard Deck under Einstellungen (Settings), Über Nodvard Deck (About Nodvard Deck), Änderungsprotokoll (Changelog).

# Nodvard Deck 0.14.0

## English

The web interface is in German only for now. Names of buttons, tabs, pages, and settings are given in German as they appear, with an English translation in brackets.

### The essentials

Update requests to the update helper are now signed. This is a security tightening that needs one manual step after the update.

### What you need to do

- **Renew the update helper and store the signing key (only with an update helper):** From 0.14.0 on, Deck sends updates and rollbacks only in signed form, and the helper executes only signed requests. After updating to 0.14.0, the buttons "Jetzt aktualisieren" (Update now) and "Zurück zu Version ..." (Back to version ...) stay locked until you have renewed the helper and stored this installation's public key in it. The card names the reason. You are not locked out: your data and access stay, and updating by hand following the guide under "Updates" still works. The steps are in [deploy/README.md](../../../deploy/README.md#schlüssel-für-update-anforderungen) in the section "Schlüssel für Update-Anforderungen" (Key for update requests): first renew the helper image (`docker compose pull updater`, then `docker compose up -d updater`), then create the key and place it in the helper.
- **Without an update helper**, nothing changes for you.

### Security

- **Signed requests:** Deck signs every request to the update helper with its own key per installation. For every update, the helper additionally requires the release approval, and it rejects missing, forged, repeated, and expired signatures. The rollback is signed as well. The helper no longer executes unsigned requests.

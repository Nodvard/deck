# Nodvard Deck 0.14.1: fixes for 0.14

## English

The web interface is in German only for now. Names of buttons, tabs, pages, and settings are given in German as they appear, with an English translation in brackets.

### The essentials

A pure bugfix release, two days after 0.14.0. It fixes the most important problems you reported since 0.14.0 and the ones we found ourselves. New features come with the next version.

- **CVE matching:** matching packages against known vulnerabilities on Debian and Proxmox servers no longer aborts and only reports vulnerabilities for which an update exists.
- **Shield with root login:** SSH hardening and Fail2ban now also work on servers where Deck logs in as root.
- **German system language:** servers with a German system language count pending updates correctly again.
- **Docker:** Docker 29 shows orphaned images again, unhealthy containers are yellow instead of green, and Deck says clearly when Docker Compose is missing.
- **Network drives:** a hanging network drive no longer takes down server status and the live view.

### What you need to do

- Nothing special. With the update helper, update as usual via "Jetzt aktualisieren" (update now).

### Security

- Login and logout check input more strictly and count failed attempts reliably.
- Overly complex image files are rejected when uploading a logo.
- Shield: SSH hardening and Fail2ban settings also work on servers with root login. Deck shows the state there without placing the helper script on the server.
- SSH hardening no longer shows raw server output when checking the state but a fixed hint; the details are in the container log.
- **HTTPS requirement can be turned off:** if you run other services without HTTPS under the same host name, you can turn off the browser HTTPS requirement with `NODVARD_DECK_HSTS=false`, also for the rescue page. Without it, nothing changes.

### Fixed

- **Network drives:** server status and the live view stay reachable when a network drive does not respond. Network drives are no longer queried and appear as a line "Belegung nicht gemessen" (usage not measured) below the disk table; a hanging disk command is stopped after five seconds. If disk usage cannot be read, server status shows a warning.
- **CVE matching:** the check no longer aborts when Debian has not yet rated individual entries, and only reports vulnerabilities for which an update exists.
- **Updates:** on servers with a German system language, pending updates are counted correctly again; before, it showed 0.
- **Docker:** the storage panel shows orphaned images on Docker 29 again. The Images tab only calls an image "ohne Namen" (without name) when Docker itself lists it as orphaned.
- **Docker:** a container whose health check fails appears yellow instead of green in the list and on the start page tile.
- **Docker:** if Docker Compose is missing on a server, stacks say so clearly instead of showing an error like "unknown flag".
- **Proxmox:** a disk whose health cannot be read (for example a USB drive) no longer counts as failed.
- **Shield weekly report:** the "Bald ablaufende Zertifikate" (certificates expiring soon) tile shows the certificates from the last check from your home network instead of always staying empty.
- **Gameserver:** if a Linux server is tagged as a game server, the page says clearly that the Valheim profile needs a Windows server. A custom command for reading the join code also runs in that case.
- **Push notifications:** "Verbindung testen" (test connection) now also checks the topic and access token for ntfy.
- **Uptime Kuma:** Deck reports an error when the address does not point to the metrics, instead of "ok" with 0 monitors.
- **Vaultwarden:** Deck no longer reports "Registrierung offen" (registration open) when registration is closed.
- **Warnings:** they keep running for all other servers when one server returns an unreadable storage or temperature line.
- **Storage sizes:** they show whole values without a needless decimal, for example "608 GB" instead of "608.0 GB".

### Good to know

- **Full list:** all changes are in Nodvard Deck under Einstellungen (Settings), Über Nodvard Deck (About Nodvard Deck), Änderungsprotokoll (Changelog).
- **Nodvard Dock** is released alongside this update.

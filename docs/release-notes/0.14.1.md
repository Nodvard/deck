# Nodvard Deck 0.14.1: Korrekturen zu 0.14

## Deutsch

### Das Wichtigste

Ein reines Korrektur-Release, zwei Tage nach 0.14.0. Es behebt die wichtigsten Fehler, die ihr uns seit 0.14.0 gemeldet habt und die wir selbst gefunden haben. Neue Funktionen kommen erst mit der nächsten Version.

- **Sicherheitslücken-Abgleich:** Der CVE-Abgleich für Debian- und Proxmox-Server bricht nicht mehr ab und meldet nur noch Lücken, für die es eine Korrektur gibt.
- **Shield als root:** SSH-Härtung und Fail2ban gehen jetzt auch auf Servern, an denen Deck als root angemeldet ist.
- **Server mit deutscher Systemsprache** zählen ausstehende Updates wieder richtig.
- **Docker:** Docker 29 zeigt verwaiste Images wieder an, ungesunde Container sind gelb statt grün, und fehlt Docker Compose, sagt Deck das klar.
- **Netzlaufwerke:** Ein hängendes Netzlaufwerk legt Server-Zustand und Live-Ansicht nicht mehr lahm.

### Was du tun musst

Nichts Besonderes. Wer mit dem Update-Helfer arbeitet, aktualisiert wie gewohnt über „Jetzt aktualisieren“.

### Sicherheit

- Anmeldung und Abmeldung prüfen Eingaben strenger und zählen Fehlversuche zuverlässig mit.
- Beim Hochladen eines Logos werden übermäßig komplexe Bilddateien abgewiesen.
- Shield: SSH-Härtung und Fail2ban-Einstellungen gehen auch auf Servern mit root-Anmeldung. Den Zustand zeigt Deck dort an, ohne das Hilfsskript auf dem Server abzulegen.
- Die SSH-Härtung zeigt beim Prüfen des Zustands keine rohe Ausgabe des Servers mehr an, sondern einen festen Hinweis; die Einzelheiten stehen im Container-Protokoll.
- **HTTPS-Pflicht abschaltbar:** Wer unter demselben Rechnernamen noch andere Dienste ohne HTTPS betreibt, kann die HTTPS-Pflicht für den Browser mit `NODVARD_DECK_HSTS=false` abschalten, auch für die Notseite. Ohne die Angabe bleibt alles wie bisher.

### Behoben

- **Netzlaufwerke:** Server-Zustand und Live-Ansicht bleiben erreichbar, wenn ein Netzlaufwerk nicht antwortet. Netzlaufwerke werden nicht mehr abgefragt und stehen als Zeile „Belegung nicht gemessen“ unter der Plattentabelle; ein hängender Plattenbefehl wird nach fünf Sekunden abgebrochen. Lässt sich die Belegung nicht lesen, steht das als Warnung im Server-Zustand.
- **Sicherheitslücken-Abgleich (CVE):** Der Abgleich bricht nicht mehr ab, wenn Debian einzelne Einträge noch nicht bewertet hat, und meldet nur Lücken, für die ein Update bereitsteht. Einträge ohne Korrektur, noch nicht bewertete und Pakete, die nicht aus Debian stammen, werden gezählt und unter dem Ergebnis angezeigt.
- **Updates:** Auf Servern mit deutscher Systemsprache werden ausstehende Updates wieder richtig gezählt; vorher stand dort 0.
- **Docker:** Die Speicher-Tafel zeigt auf Docker 29 wieder die verwaisten Images. Der Reiter Images nennt ein Image nur noch „ohne Namen“, wenn Docker es selbst als verwaist führt.
- **Docker:** Ein Container, dessen Gesundheitsprüfung scheitert, erscheint in der Liste und auf der Kachel der Startseite gelb statt grün.
- **Docker:** Fehlt auf einem Server Docker Compose, sagen die Stacks das klar, statt eine Fehlermeldung wie „unknown flag“ zu zeigen.
- **Proxmox:** Ein Datenträger, dessen Zustand sich nicht auslesen lässt (etwa eine USB-Platte), gilt nicht mehr als defekt.
- **Shield-Wochenbericht:** Die Kachel „Bald ablaufende Zertifikate“ zeigt die Zertifikate aus der letzten Außenprüfung aus dem Heimnetz, statt immer leer zu bleiben.
- **Gameserver:** Ist ein Linux-Server als Gameserver markiert, sagt die Seite klar, dass das Valheim-Profil einen Windows-Server braucht. Ein eigener Befehl zum Lesen des Join-Codes läuft auch dann.
- **Push-Nachrichten:** „Verbindung testen“ prüft bei ntfy auch Thema und Zugriffstoken.
- **Uptime Kuma:** Deck meldet einen Fehler, wenn die Adresse nicht auf die Messwerte zeigt, statt „ok“ mit 0 Monitoren.
- **Vaultwarden:** Deck meldet nicht mehr „Registrierung offen“, wenn sie gesperrt ist.
- **Warnungen:** Sie laufen für alle anderen Server weiter, wenn ein Server eine unlesbare Speicher- oder Temperaturzeile liefert.
- **Speichergrößen:** Sie zeigen ganze Werte ohne überflüssige Nachkommastelle, zum Beispiel „608 GB“ statt „608.0 GB“.

### Gut zu wissen

- **Vollständige Liste:** Alle Änderungen stehen in Nodvard Deck unter Einstellungen, Über Nodvard Deck, Änderungsprotokoll.
- **Nodvard Dock** erscheint im selben Zug als eigenes Release.

## Nodvard Deck 0.14.1 – fixes for 0.14

A pure bugfix release, two days after 0.14.0. It fixes what you reported since 0.14 and what we found ourselves. New features come with the next version.

### Highlights

- **CVE matching** for Debian and Proxmox servers no longer aborts and only reports vulnerabilities that have a fix.
- **Shield with root login:** SSH hardening and Fail2ban now also work on servers where Deck logs in as root.
- **Servers with a German system language** count pending updates correctly again.
- **Docker:** orphaned images on Docker 29, a yellow instead of green dot for unhealthy containers, and a clear message when Docker Compose is missing.
- **Network drives:** a hanging network drive no longer takes down server status and the live view.

### Security

- Login and logout check input more strictly and count failed attempts reliably.
- Overly complex image files are rejected when uploading a logo.
- SSH hardening no longer shows raw server output when checking the state; details go to the container log.
- If you run other services without HTTPS under the same host name, you can turn off the browser HTTPS requirement with `NODVARD_DECK_HSTS=false` (also for the rescue page). Without it nothing changes.

### Fixed

- Server status and the live view stay reachable when a network drive does not respond.
- Pending updates are counted again on servers with a German system language.
- Docker 29 shows orphaned images again; unhealthy containers are yellow instead of green; a clear message when Docker Compose is missing.
- Proxmox: disks whose health cannot be read (e.g. USB drives) are shown as unknown, not failed.
- Shield weekly report: the expiring certificates tile now shows certificates from the last outside check.
- Gameserver, ntfy, Uptime Kuma and Vaultwarden checks report correctly; warnings keep running for all other servers if one server returns unreadable data.
- Storage sizes show whole values, e.g. “608 GB” instead of “608.0 GB”.

### What you need to do

Nothing special. With the update helper, update as usual via “Update now”.

**Nodvard Dock** is released alongside this update. The full list is in Nodvard Deck under Settings, About Nodvard Deck, Changelog.
